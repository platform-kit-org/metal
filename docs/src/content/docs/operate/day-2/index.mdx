Day 2 is all the work after the install, while workloads run on the nodes.
The rule does not change: the operator proposes, a person approves, the operator does it.
If `selfApproval` is `Forbidden`, a second person approves. See [](howto:approval-permissions).

## Daily control

| Task | Command | Approval |
| --- | --- | --- |
| [](howto:approve-hold-retry) | [](cli:approve), [](cli:hold), [](cli:retry), [](cli:abort) | Is the approval |
| [](howto:maintenance-windows) | `kubectl apply` | None. A window only sets the time. |
| [](howto:maintenance-mode) | `kubectl annotate host` | None |
| [](howto:monitor) | [](cli:status), [](cli:top) | None. Reads only. |
