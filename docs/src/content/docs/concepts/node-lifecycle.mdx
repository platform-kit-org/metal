A [](kind:TalosNode) is a member of its cluster while a claim gives it a machine.
For etcd, the operator does not trust these counts. Before a control plane joins or leaves, it reads the member list from etcd.

<AddRemoveNodes />

## Terms

<dl>
  <dt>Member</dt>
  <dd>A TalosNode that a claim gave a machine. A TalosNode that waits for a machine is in `status.unassignedNodes` and does not lower `Available`.</dd>
  <dt>Join serialization</dt>
  <dd>A control plane boot waits with `EtcdJoinWaiting` while another control plane boots or leaves. It also waits while a member is not healthy, a member is a learner, or etcd has a member with the same name.</dd>
  <dt>Leave verdict</dt>
  <dd>The decision whether a control plane can leave etcd now. See [Leave rules](#leave-rules).</dd>
  <dt>ack-etcd-risk</dt>
  <dd>The annotation `metal.platform-kit.org/ack-etcd-risk` on the claim or the TalosNode. Its value is your username and your reason for an unsafe removal.</dd>
  <dt>RemovalBlocked</dt>
  <dd>The condition of a TalosNode that is deleted. It waits for the release of its machine or the removal of its etcd member.</dd>
</dl>

## Leave rules

| After the removal | Without `metal.platform-kit.org/ack-etcd-risk` |
| --- | --- |
| No member stays | Refused |
| Fewer healthy members than a majority | Refused |
| An even number of members | Refused |
| The leader leaves with other control planes | Waits, the leader leaves last |
| Another control plane joins or leaves | Waits |
| The member list cannot be read | Waits |

[](cli:scale), [](cli:replace) and [](cli:reinstall) accept `--ack-etcd-risk "<reason>"`.

## Sizes

| Control planes | Failures tolerated |
| --- | --- |
| 1 | 0 |
| 2 | 0 |
| 3 | 1 |
| 4 | 1 |
| 5 | 2 |

Use 1, 3 or 5. An even count costs one more machine for no more safety.

## Change requests

| Command | Effect |
| --- | --- |
| [](cli:scale) | Writes or deletes claims to reach a size |
| [](cli:replace) | Moves a node to another machine. The operator releases the old machine first. |
| [](cli:reinstall) | Drains, resets and installs a node again on the same machine |
