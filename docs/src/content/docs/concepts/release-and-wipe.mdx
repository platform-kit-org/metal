When a claim goes, the machine returns to the pool. Its disk must not hold the old node.
If the old disk boots, the machine comes back as a node that no longer belongs, with the keys of its cluster.

## Rules

1. A Host with `DiskWiped=False` (reason `InstalledNodeRemains`) carries the annotation `metal.platform-kit.org/disk-not-wiped`. It gets no install and no other operation that turns it on.
2. [](cli:wipe) asks for the wipe. A person approves it. The wipe boots a Talos image with `talos.experimental.wipe=system`. The machine ends in Talos maintenance mode with an empty disk.
3. If you know that the disk is empty, remove the annotation and set `metal.platform-kit.org/wipe-waived` in the same request. See [](howto:wipe-and-decommission).
4. The hand-off record ([`status.handOff`](kind:HostClaim#status.handOff)) decides whether a release needs approval. It changes only through [](cli:reinstall), [](cli:replace) or a removal. Each one resets the disk first.
